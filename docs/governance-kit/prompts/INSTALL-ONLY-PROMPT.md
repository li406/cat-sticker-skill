# 仅安装轻量项目治理，不改变产品状态

请在当前仓库安装 Owner-Driven 轻量治理制度。

本轮不要开发产品功能。

## 1. 检查现有规则

读取：

- AGENTS.md / Agent instructions
- PRODUCT-GOAL.md
- ROADMAP.md
- CURRENT-STAGE.md
- BACKLOG.md
- docs/ops

如果已有等价文件，不重复创建。

## 2. 安装长期规则

对 Codex：

将 `AGENTS-GOVERNANCE-SNIPPET.md` 的核心规则以最小冲突方式合并进根 `AGENTS.md`。

其他 Agent：

写入其项目级长期 rules/instructions。

保留仍有效的安全、权限、测试、Git 和项目特定规则。

## 3. 安装详细手册

确保存在：

`docs/ops/PROJECT-OPERATING-MANUAL.md`

## 4. 不改变项目事实

本轮不要自行重写：

- PRODUCT-GOAL
- ROADMAP
- CURRENT-STAGE
- BACKLOG

如果这些文件还不存在，只报告缺失，不在“仅安装”模式下猜测生成。

## 5. Git

检查 diff、敏感信息，commit，并在已有授权时 push。

## 6. 停止

报告安装了什么、冲突如何处理、是否可以进入项目迁移或正式开发。

本轮不要继续产品开发。
